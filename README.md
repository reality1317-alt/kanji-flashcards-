# 漢字フラッシュカード

小学生向けの漢字復習アプリです。
iPad・Android・パソコンのブラウザで使用できます。

## アプリを開く

https://reality1317-alt.github.io/kanji-flashcards-/

## 現在の問題

総合復習問題（61〜80）

## 使い方

1. 表面の問題を読む
2. カードをタップして答えを確認する
3. 「正解」または「間違えた」を押す
4. 最後に正解数と間違えた問題を確認する
5. 「もう一度」で再挑戦する

## 今後の問題追加方法

1. 新しい漢字問題の写真をChatGPTに送る
2. 問題文と正しい漢字を確認する
3. HTMLを更新する
4. GitHubに変更を反映する
5. 公開URLで動作確認する

## ファイル構成

- index.html：漢字フラッシュカード本体
- README.md：この説明書

※ アプリ更新時は、既存の問題・デザイン・動作を維持すること。
